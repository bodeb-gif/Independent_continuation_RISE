Modern ProQuest analysis

Prepared October 20, 2026 • Separate 2011–2026 study • Exploratory evaluation

The claim RNN and the downturn models answer different questions. The frozen RNN estimates whether an extracted forecast is correct. The separate monthly logistic models estimate recession onset or production decline. Neither establishes what will certainly happen.

Data and validation

Imported 91,118 claims. Excluded all 33,071 empty records from model inputs, including 20,580 repeated empty records in 2011. Preserved source bytes and row addresses. Excluded the 19 default-kept verification exceptions from primary inputs, leaving 91,099 claims. Historical and modern exports remain separate.

The author's 150 historical human reviews reconcile locally: 105 included, 44 excluded, 1 unclear across 149 articles. Direction agreement is 94/105 and scope agreement 65/105 among included claims. This positive-candidate sample cannot measure recall and contains no modern claims. It supports assessment of the extraction process, not validation of every modern forecast. Earlier AI/model-label exposure remains documented. Current-state coding conventions differ, so its agreement and the all-eleven-field count are not valid overall accuracy measures.

Prior exposure to modern results remains unknown. The original full intake gate was not certified: processing metadata are incomplete. The dated scope amendment authorizes this exploratory analysis without changing the original frozen gate.

Frozen claim-model evaluation

56,886 mature, supported claims from 23,775 articles were scored; all models use identical evaluation rows and equal total weight per article. The remaining 32,604 claims have unsupported scope/topic/direction/horizon, 1,138 are immature, and 471 cross missing reference observations. Those gaps are October 2025 CPI and unemployment observations and were not imputed.

Historical reproduction matched 56,807 saved rows across all original arms, with maximum probability error below 3×10⁻⁸. The primary ensemble remains fixed. All 30 frozen artifacts are unchanged.

The primary RNN has Brier 0.1770 and AUC 0.7376; the history logistic control has Brier 0.1936 and AUC 0.6545. The RNN with both polarization measures has Brier 0.1742 and AUC 0.7486 as a secondary result. The historically selected GRU8 challenger does not improve primary Brier. Do not select the modern winner retroactively.

Employment is a failure mode: the primary RNN's employment AUC is 0.3064, versus 0.7675 for general business, 0.7881 for markets and 0.9060 for prices. Pooled performance does not justify using it for every topic. Always predicting “incorrect” would achieve 71.3% article-weighted classification accuracy in this sample; the primary RNN reaches 75.4%, so accuracy alone overstates the result.

Separate 12-month downturn forecasts

Latest complete newspaper month: August 2026. Latest forecast origin: September 2026, covering September 2026–August 2027. This is not an October-origin forecast. Inputs have 56 recent general-business articles from five newspapers over three observed months. Models refit annually in January; the latest saved coefficients are the January 2026 fit.

Recession means a new 0→1 transition in USREC during the target window, not a recession already under way. Production decline means the monthly INDPRO index at August 2027 is below August 2026; the 2% variant is a separate severity sensitivity. These events are different. USREC is an interpretation of NBER retrospective dating; industrial production is a sectoral production measure, not all GDP. See USREC and INDPRO.

Research estimates: 6.9% for recession onset, 28.0% for any production decline, and 22.4% for a decline greater than 2%. Candidate probabilities vary: recession estimates range from 6.9% to 27.0%. The selected production-decline estimate is essentially the same as the latest historical base rate (28.0%).

Selection used only mature pre-2011 rolling Brier results, comparing a base rate and four press/polarization logistic variants. Modern rolling evaluation is separate. The selected recession model improved Brier from 0.0832 to 0.0696; the production-decline model from 0.2570 to 0.2272. The selected greater-than-2% model was worse than its base-rate comparator (0.1470 versus 0.1373); retain that unfavorable result.

These estimates do not yet support a strong downturn call. Modern recession evaluation contains only one distinct onset (March 2020), represented by 12 overlapping positive months. The selected-model improvements have paired block intervals crossing zero. A 92.2% recession classification accuracy is also achieved by always predicting no onset at a 0.5 threshold. Model probabilities are exploratory, not established calibrated risks.

Reproducibility and remaining work

Original outcome snapshots are preserved with hashes. Claim maturity requires endpoint plus three months strictly before October 2026. Recession labels use a conservative 24-month allowance; production uses three months. This is approximate historical availability with revised outcomes, not archived real-time label vintages. No macroeconomic values or outcome columns enter the predictor features. Political features use actual lagged House votes, not NOMINATE scores.

Future-publication/vote mutation tests passed. All 163 main-suite checks and 16 intake/modern checks passed. No new model-selection or permutation p-value claim was made. Source-validation errors, changing query/coverage, the full-intake metadata gaps and very few modern recession events remain limitations.

Next priorities: obtain complete September-onward corpus coverage for a current forecast; reconcile upstream processing metadata; investigate the employment failure without flipping predictions on the test set; evaluate against an archived macroeconomic baseline; and assess forecasts prospectively as outcomes mature. Refit/retune any successor on explicitly separated development data and freeze its future evaluation.

Entry points: src/proquest_modern_analysis.py and src/proquest_downturn.py. Run manifest, model bundles, source exclusions, predictions, outcomes, calibration, subgroup metrics and block intervals accompany this report.
